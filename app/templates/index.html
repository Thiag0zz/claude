Como funciona

Três passos para começar a consultar.

1

Gere sua chave

Informe nome e e-mail e receba uma chave de acesso na hora.

2

Faça a requisição

Envie a chave no cabeçalho X-API-Key e use os filtros que precisar.

3

Use os dados

Respostas em JSON paginado, com link direto para o contrato no PNCP.

Exemplo

Contratos de SP acima de R$ 1 milhão, do maior para o menor valor.

curl "{{ request.base_url }}v1/contratos?uf=SP&valor_min=1000000&ordem=maior_valor" \
  -H "X-API-Key: SUA_CHAVE"
