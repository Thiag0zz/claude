Documentação

A API devolve contratos publicados no Portal Nacional de Contratações Públicas (PNCP), normalizados e pesquisáveis. URL base: {{ base_url }}

Autenticação

Toda requisição precisa da sua chave no cabeçalho X-API-Key. Gere uma chave se ainda não tiver.

curl "{{ base_url }}/v1/contratos" -H "X-API-Key: SUA_CHAVE"

Buscar contratos

GET /v1/contratos com qualquer combinação dos filtros abaixo.

ParâmetroDescrição
qTexto no objeto, no nome do órgão ou do fornecedor
ufSigla da UF, ex: MG
municipioNome do município
orgao_cnpjCNPJ do órgão (com ou sem pontuação)
fornecedor_niCNPJ ou CPF do fornecedor
tipo_contratoEx: Contrato, Empenho, Outros
esferaF federal, E estadual, M municipal
valor_min, valor_maxFaixa de valor global, em reais
assinatura_de, assinatura_ateFaixa de data de assinatura (AAAA-MM-DD)
ordemrecentes (padrão), antigos, maior_valor, menor_valor
pagina, por_paginaPaginação; por_pagina vai de 1 a 100 (padrão 20)
curl "{{ base_url }}/v1/contratos?q=merenda&uf=MG&assinatura_de=2026-01-01" \
  -H "X-API-Key: SUA_CHAVE"

Python

import requests

resp = requests.get(
    "{{ base_url }}/v1/contratos",
    params={"uf": "SP", "valor_min": 1_000_000, "ordem": "maior_valor"},
    headers={"X-API-Key": "SUA_CHAVE"},
)
for contrato in resp.json()["dados"]:
    print(contrato["valor_global"], contrato["objeto"])

JavaScript

const resp = await fetch("{{ base_url }}/v1/contratos?uf=RJ", {
  headers: { "X-API-Key": "SUA_CHAVE" },
});
const { dados, total } = await resp.json();

Detalhar contrato

GET /v1/contratos/{numero_controle_pncp} devolve todos os campos, incluindo o registro original do PNCP em original_pncp.

curl "{{ base_url }}/v1/contratos/92913318000181-2-000074/2026" -H "X-API-Key: SUA_CHAVE"
